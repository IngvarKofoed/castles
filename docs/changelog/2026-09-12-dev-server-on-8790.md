# The dev server is pinned to 8790, preview to 8792

`npm run dev` now serves http://localhost:8790 and `vite preview`
http://localhost:8792, both `strictPort`. A second server on either port fails
with `Port … is already in use` rather than sliding to the next free one and
serving the page from an address nobody is watching.

## Detail
- **Preview is 8792, not the adjacent 8791, because the mockups hold 8791** —
  the README's `python3 -m http.server 8791`. 8790/8791/8792 is the project's
  one contiguous block, and the mockup line did not move.
- **No `preview` npm script was added**, deliberately: there is none today, and
  preview is run as `npx vite preview`. Adding one was out of scope.
- `vite.config.ts` is the vitest config too. The `test` block and its
  `testTimeout` rationale are untouched, and the suite and lint pass unchanged.
