# Concept reframed: risk is chosen, never imposed

The wall is now absolute (never breached); all danger lives outside, where
expansion happens. Prescribed rings are retired — land is claimed bite by
bite: palisade, stone wall behind it, tear down the old line. Monsters (orcs
fast/light, trolls slow/heavy) run readable schedules and can only be
avoided, never fought; manned watchtowers buy schedule precision.

## Detail
- Rejected: territorial monster aggression (attack only what blocks their own
  ground) — chosen aggressive: anything unfinished that is noticed is attacked.
- Rejected: nested rings kept as inner citadel walls — the old wall is
  dismantled after the new one closes, so a failed push retreats behind it.
- Rejected: mourning/morale systems — a death is just the loss; the labour
  model makes it felt.
- Constraint that binds: supply failures must plateau, never spiral —
  colonists feed themselves regardless of task queues.
- Constraint: an attack on a palisade ends only when the monster's schedule
  pulls it away — nothing the player does drives one off.
- ARCHITECTURE.md reconciled the same day: computed enclosure replaces the
  octagon, walls get a lifecycle, truth-vs-knowledge split. The mockups
  (`mockup.html`, `mockup3d.html`) predate the reframe and show the old ring
  model.
